# Steuer von Kategorien und Produkten ändern

Hier erfährst du, wie du die Mehrwertsteuer von Kategorien und Produkten änderst.

1. Gehe in der Orderlyze App ins Menü und tippe auf Verwaltung.

2. Gehe im Menü der Verwaltung auf "Kategorien".

3. Klicke bei einer beliebigen Kategorie ganz rechts auf das "Bearbeiten" Symbol.

4. Wähle anschließend bei "Mehrwertsteuer" die entsprechende Steuer aus. Wichtig: Wenn man bei einer Überkategorie eine Mehrwertsteuer einstellt, dann kann man bei einer Unterkategorie dier Mehrwertsteuer nicht ändern.

5. Klicke anschließend unten auf "Speichern".

Achtung: Wenn du bei einer Kategorie die Mehrwertsteuer änderst, dann ändert es die Mehrwertsteuer bei allen Produkten innerhalb dieser Kategorie.
